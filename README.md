# Skimventory

Skimventory is a scan-first personal inventory app for books, tools, pantry items, and anything else you need to keep track of. You point your camera at a barcode, the app looks the item up from a public product database and saves it to your inventory, and you can add and manage your items anywhere, with data synced to your account.

Features
Main item type and mock data
Reusable item card
Inventory list screen
Item details component
Supabase auth
Barcode scanning
Product lookup API
Add / edit / delete items
Item detail screen (own route)
Categories and filtering
Empty and loading states
Local persistence (settings / simple copy)
Cover images in Supabase Storage
